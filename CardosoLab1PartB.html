Lab 1 Part B - Terms and Definitions

1) DOCTYPE Statement
The DOCTYPE defines the version of HTML used in the document. It helps makes sure the browser renders the page correctly.
2) How to use <ol>, <ul>, <dl>
  • <ol>: Creates an Ordered Numbered list. Example:
    1. First item
    2. Sedond item
  • <ul>: Creates an Unordered Bulleted list. Example:
    • Soccer
    • Baseball
  • <dl>: Creates a definition list, which pairs terms (<dt>) with a description (<dd>).
3) Difference between Text Editor and Word Processor
A Text Editor is a program used to write and edit plaintext (Notepad). A Word Processor is a software used to create formatted documents with fonts, images, and styles (Google Docs, Microsoft Word).
4) Client-Server Model
The Client-Server Model is a distributed computing architecture where tasks are divided between servers ( service providers) and clients (service requests) connceted over a network.
5) Network Protocols
FTP ( File Transer Protocol): A protocol that is used to transfer files between a client and a server on a computer network.
HTTP (Hypertext Transfer Protocol): A protocol that defines how clients (like web browsers) and servers communicate to exchange information on the internet.
TCP/IP (Transmission Control Potocol/ Internet Protocol): A suite of protocols for reliable data transfer over networks, while HTML is an applicatuon - layer used to structure and display web content.
